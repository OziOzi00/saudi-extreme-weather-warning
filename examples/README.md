# 联调样例数据

本目录的三个 NetCDF 是成员 A 从 GraphCast `2020-08-20T00:00:00Z` 起报生成的 MAZU-like v1 小型联调样例，分别对应 24、48、72 小时窗口。

它们用于成员 B 开发 NetCDF 读取和成员 C 了解交接接口；字段、单位、网格和元数据以 [数据交接契约](../docs/数据交接契约.md) 为准。该日期仅为流程演示，不得称为已确认极端灾害个例。

`examples/data/` 保存稳定的小型接口样例；`handoff/mazu_like/` 保存可供协作消费的正式派生交接件。两者都不得放入 GraphCast 原始缓存、MAZU 全量指标、IMERG/GHCN 原始文件或批量大输出。

三个样例现同时作为 A 侧自动验收、错误注入和三个 lead 连续性测试夹具。测试只修改临时副本，不改动版本化样例。
