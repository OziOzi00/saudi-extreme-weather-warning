# 沙特 MAZU 极端天气预警项目：统一技术路线 v1

## 项目要解决什么

本项目构建面向沙特阿拉伯强降水与高温/热浪的可追溯预警原型：将气象预报转换为统一指标，依据可审查的风险规则生成区域风险结论，再用图谱组织证据和生成报告。

## 总体路线

```text
MAZU 2025 历史指标
  → 指标分布与候选阈值
  → 冻结风险规则 v1
  → 风险 JSON
  → 知识图谱与可追溯报告

GraphCast 2020 历史预报
  → MAZU-like v1 指标（0.25 degree）
  → 已冻结的风险规则
  → 风险 JSON
  → 图谱与报告
  → IMERG/GHCN/灾害记录分层验证
```

MAZU 2025 用于开发、标定和内部一致性检查，不是未来预报模型。GraphCast 2020 用于规则冻结后的独立历史回放。天气层验证和灾害影响层验证必须分开进行。

## 当前实现状态

成员 A 已完成 GraphCast 读取、缓存、沙特区域处理、MAZU-like v1 转换、24/48/72 小时批处理，以及一个 `2020-08-20T00:00:00Z` 的演示交接个例。A 还协助完成了 MAZU 2025 字段覆盖审计、13 个 ADM1 区域注册和描述统计。演示个例只证明流程可运行，不证明已确认极端灾害。

成员 B 仍需复核跨源时间语义、论证阈值、取得真实观测并冻结规则；草案风险引擎不等于正式结果。成员 C 的独立开发骨架已由 A 协助推进，包括阿拉伯语名称、候选案例/灾害真值、Neo4j bundle/导入器和受控报告模板；案例、对照和证据尚待 C/B/全队复核，Neo4j 未声明部署，正式报告仍依赖冻结 Risk JSON。

## 三人边界

| 成员 | 负责 | 不负责 |
| --- | --- | --- |
| A | GraphCast → MAZU-like NetCDF、缓存、批处理 | 风险阈值与灾害结论 |
| B | MAZU 2025 统计、规则、风险 JSON、天气层评估 | 重算 A 的气象指标 |
| C | 区域与灾害真值、图谱、证据、报告 | 重算指标或风险分数 |
