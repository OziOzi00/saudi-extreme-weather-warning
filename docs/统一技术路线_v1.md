# 沙特 MAZU 极端天气预警项目：统一技术路线 v1

状态：2026-07-19 结项主线更新。文件名保留 `v1` 以兼容已有链接，以下内容描述当前最终实现。

## 项目要解决什么

本项目构建面向沙特阿拉伯强降水与高温/热浪的可追溯历史回放研究原型：将 GraphCast 预报转换为统一指标，由基础风险规则与预测时知识图谱纠错共同生成区域联合风险，再由 Neo4j 和受控 Agent 编排、解释、锁定并在事后验证。项目不提供实时业务预警。

## 总体路线

```text
MAZU 2025 历史指标
  → 指标语义、分布与候选规则开发（方法参考，不作为预测输入）

GraphCast 2018 / 2020 历史预报
  → MAZU-like v1 指标（0.25 degree；24/48/72h）
  → 13个 ADM1 × 11项区域指标摘要
  → 基础风险规则
  → 预测时知识图谱一致性纠错
  → 联合最终风险与无真值预测锁
  → Neo4j 在线关系查询
  → 八阶段编排 Agent
  → 系统结论与大模型独立意见双轨报告
  → 两轨均锁定后才接入 IMERG / SSOD / GHCN / 灾害记录
  → 天气层与影响层事后验证
```

MAZU 2025 用于开发、标定和内部一致性检查，不是未来预报模型。GraphCast 2018/2020 用于历史回放。当前实验语义是 `retrospective_transfer_replay`：验证“以 MAZU 2025 建立的方法能否迁移到其他年份的历史 GraphCast 输入”，不能表述为“在 2020 年实时使用了 2025 数据”。预测阶段不得读取同期或事后观测、案例角色、灾害答案或评分；系统结论和大模型独立意见均锁定后，天气层与灾害影响层验证才可运行。

## 当前实现状态

成员 A 已完成 GraphCast 读取、缓存、沙特区域处理、MAZU-like v1 转换和 24/48/72 小时批处理。仓库当前共有81份小型交接 NetCDF（原20个批准案例加demo形成63份，2018跨年扩展再增加18份），均保留可追溯验收记录；A还协助完成 MAZU 2025 字段覆盖审计、13个ADM1区域注册和描述统计。

天气层已形成225/225条accepted development配对。当前研究评估对象已由“风险规则单独输出＋图谱影子建议”升级为“基础规则＋预测时图谱纠错＋联合最终风险”：暴雨共搜索234组，选中方案在development事件窗5/5、对照4/4；既有独立划分非盲回放为事件5/5、对照6/6，但图谱触发0次，尚未证明独立纠错增益。高温搜索2316组，无方案通过全部门槛；选择锁后回放的既有独立事件4/4命中，但没有独立对照，正式预警继续blocked。预测锁严格排除同期观测、案例角色、灾害影响和评分答案；旧v2影子方案保留审计，不再代表当前联合研究主线。

联合Agent的最后一公里也已完成：锁定预测通过独立`JointPrediction*`标签进入本地在线Neo4j，八阶段编排器真实查询24/48/72小时关系后调用Luna或Terra。最终四组批处理使用26个案例、78份NetCDF，生成29份报告、87条窗口级双轨预测和957行过程指标。系统结论不可被大模型改写；大模型独立意见单独锁定、单独评分。暴雨系统在development为5命中/0漏报/0误报/4正确否定，在既有独立划分回放为5/0/0/6；高温development为9/5/8/15，仍未通过门槛，独立集又没有负样本，因此继续`research_only_blocked`。

## 三人边界

| 成员 | 负责 | 不负责 |
| --- | --- | --- |
| A | GraphCast → MAZU-like NetCDF、缓存、批处理 | 风险阈值与灾害结论 |
| B | MAZU 2025 统计、规则、风险 JSON、天气层评估 | 重算 A 的气象指标 |
| C | 区域与灾害真值、图谱、证据、报告 | 重算指标或风险分数 |
