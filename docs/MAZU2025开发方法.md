# MAZU 2025 开发与审计说明

## 数据定位

MAZU 2025 用于理解指标物理意义、统计沙特区域的季节/区域分布、提出并校准风险阈值与权重，以及测试后半段接口。它不是未来预报模型，也不能单独证明系统具备未来预警能力。

成员 A 于 2026-07-15 协助完成了第一轮技术审计。真实数据位于本地 `MAZU指标/indicators/`，文件模式为 `saudi_indicators_YYYYMMDD.nc`；共 365 份、约 5.42 GB，覆盖 2025-01-01 至 2025-12-31。原始文件继续留在本地，不提交 Git。

## 审计范围与结论

- 每日文件包含 82–91 个变量；11 个共享指标均在数据集中出现。
- 共享指标使用二维 `latitude × longitude` 网格，大小为 `160 × 220`。
- 纬度范围约 `16.0–31.9°N`，经度范围约 `34.0–55.9°E`，步长 `0.1°`。
- 11 个字段的名称和单位与 MAZU-like v1 一致；所有扫描到的有限值均未超出审计脚本使用的宽松物理范围。
- 字段并非每天都有有效值，特别是高空动力和水汽字段；规则必须显式处理缺测。
- 部分文件的全局属性含原生产机器的绝对路径，仅可作为历史信息，不能用于仓库复现或数据来源标识。

完整覆盖率、极值、缺失日期和 QC 结果见 [`../manifests/mazu_2025_indicator_coverage.csv`](../manifests/mazu_2025_indicator_coverage.csv)。

## 缺测特征

- 近地面指标有效 362–364 天，缺失主要集中在 2025-01-02、01-30 和 08-17 至 08-20 的部分字段。
- `pwat`、`ivt`、850/200 hPa 风场、`omega500` 和 500 hPa 位势高度有效 291–293 天；主要缺口是 1 月初至 3 月中旬，另有少量 3 月和 8 月日期。
- 在有效日期中，大多数字段的二维网格是完整的；`t2m_c`、`ivt`、`wind850_speed`、`wind_shear_850_200` 个别日期存在整日空值。

Risk JSON 应把缺失条件写入 `missing_evidence`，不能用 0 代替；规则不得因某个辅助字段缺失而自动判为低风险。

## ADM1 描述统计（A 协助完成）

已使用统一的 13 个 ADM1 边界完成年度和 DJF/MAM/JJA/SON 四季统计，结果位于 [`../handoff/mazu_statistics/`](../handoff/mazu_statistics/)。每个区域、指标、时期记录：

- 有效天数；
- 每日区域纬度余弦加权均值的 P50/P90/P95/最大值；
- 每日区域最大值的 P50/P90/P95/最大值；
- 每日空间 P95 的 P50/P90/P95/最大值。

这些是描述统计和候选阈值依据，不是已冻结规则。边界代表年份为 2017；跨源时间语义已形成可审查分级，详见[指标时间语义与聚合口径](指标时间语义与聚合口径.md)，仍待 B/全队复核。

## 规则开发顺序

```text
字段/单位审计（已完成）
→ 明确跨源时间聚合语义（A 协助形成草案）
→ ADM1 边界、区域聚合和描述性 P90/P95（A 协助完成）
→ 结合时间语义和描述统计提出候选阈值（A 协助完成草案）
→ YAML 候选规则、草案引擎与内部一致性检查（A 协助完成）
→ B/全队结合案例和观测验证复核
→ 全队冻结 risk_rule_v1
→ GraphCast 2020 独立回放
```

不得用同一过程同时调参又宣称独立验证；2020 回放时规则必须预先冻结。天气预测正确与灾害影响发生是两个独立问题，分别验证。

## 复现审计

运行脚本：`scripts/audit_mazu_2025.py`。当前 Windows 默认 Python/NetCDF4 对中文路径支持异常时，可临时建立英文目录联接：

```powershell
$source = (Get-Item -LiteralPath 'MAZU指标\indicators').FullName
$junction = Join-Path $env:TEMP 'mazu2025_indicators_ascii'
New-Item -ItemType Junction -Path $junction -Target $source | Out-Null
python scripts\audit_mazu_2025.py --input-dir $junction
python -m scripts.summarize_mazu_2025_adm1 --input-dir $junction
[System.IO.Directory]::Delete([System.IO.Path]::GetFullPath($junction))
```

该联接不复制或修改原始数据；输出是体积很小、可提交协作的覆盖率汇总。
