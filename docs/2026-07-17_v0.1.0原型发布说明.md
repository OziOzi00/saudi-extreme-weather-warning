# v0.1.0 稳定研究原型发布说明

## 发布结论

`v0.1.0-prototype` 冻结当前可复验的研究原型。该版本已经把 GraphCast 2020 历史预报转换为 MAZU-like 指标，并贯通冻结暴雨规则、Risk JSON、知识图谱 bundle 与受控报告。它适合课程展示、团队交接和后续迭代基线，不是实时业务预报服务。

## 一键验收

在已安装开发依赖的仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_prototype_demo.ps1
```

该命令不下载原始数据、不重新运行 GraphCast、不启动 Neo4j，完成以下只读复验：

1. 根据版本化 manifest 和交接件生成确定性的 `handoff/prototype_demo/demo_summary.json`；
2. 验收 15 份 development 与 18 份 independent_test 冻结暴雨 Risk JSON；
3. 检查暴雨冻结、高温阻塞、影响评估边界和本地 Neo4j 联调记录；
4. 运行原型发布边界测试。

需要从原始数据重建各阶段时，继续使用 A 侧交付、冻结 development、锁定独立暴雨和 Neo4j 实机联调的专用脚本；这些脚本可能依赖 Git 忽略的本地原始数据或本地服务。

## 演示路径

正向案例使用 `20200725_00 / SA-14`：lead048 为中风险，lead072 为高风险。展示顺序建议为 MAZU-like NetCDF → Risk JSON → warning 报告 → 综合图谱 bundle。

已知漏报使用 `20200501_00 / SA-09`：lead024 与 lead048 均为低风险。lead024 主要是天气预报低估；lead048 同时暴露区域 P95 对局地极值的尺度缺口。该案例用于说明误差拆解和诚实边界，冻结规则没有据此回调。

## 禁止外推

- 不得将历史回放写成实时 GraphCast 推理或业务预警服务；
- 不得用小型独立暴雨样本宣称跨年份泛化能力；
- 不得将影响正例覆盖率写成准确率、精确率、特异度或误报率；
- 不得将高温规则描述为已冻结或已独立验证；
- 不得将本地 Neo4j development 联调描述为生产部署。
