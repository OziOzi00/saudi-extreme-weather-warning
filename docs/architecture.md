# v1 架构

```text
GraphCast 2020 ──成员 A──> MAZU-like NetCDF ──成员 B──> Risk JSON ──成员 C──> Neo4j + Markdown report
                                  │                  │                       │
MAZU 2025 ────────────────────────┘                  │                       │
IMERG / GHCN / 灾情记录 ─────────────────────────────┴───────────────────────┘
```

## 边界

- **成员 A** 仅负责预测数据读取、裁剪、指标转换、NetCDF 元数据和批处理。
- **成员 B** 仅负责 2025 年开发统计、可解释规则、评分、行政区聚合和评估指标。
- **成员 C** 仅负责真实观测/事件表、Neo4j 图谱、证据组织和报告。
- 数值网格保留在 NetCDF；图谱只存区域级摘要、规则与证据。

## 开发顺序

先在 MAZU 2025 上验证接口和规则，再冻结规则；仅在冻结后对 GraphCast 2020 进行独立回放评估。不可依据 2020 测试结果反向调参。
