# 2026-07-17 独立暴雨评估结果

## 执行边界

暴雨v2在development冻结后，才一次性打开4个`independent_test`暴雨案例。执行锁位于`manifests/independent_heavy_rain_evaluation_lock.json`，固定了规则SHA-256、32日IMERG文件清单、416行ADM1日摘要和案例ID，并声明不得根据测试结果回调规则。

高温独立案例没有读取。此次结论只适用于天气层暴雨原型，不代表高温、灾害影响层或全年业务效果。

## 数据完整性

- 新补齐2020-07-11、07-25、11-25、11-27四个IMERG Final Run V07B UTC日文件。
- 本地IMERG集合现为32日、385,242,883字节；32/32份ZIP和SHA-256均有清单。
- 4个案例、6个案例—区域组合、3个lead和3种聚合形成54/54条accepted配对，缺失为0。
- `spatial_p95`的18条配对使用冻结暴雨v2中等级门槛；其他聚合只计算连续误差，不混用分类门槛。

冻结`spatial_p95`门槛的18条独立分类结果为：命中6、漏报0、空报0、正确否定12，POD=1、FAR=0、CSI=1。lead024没有观测或预报越过门槛，因此该lead的POD/FAR/CSI保持空白，不写成0。

按案例目标时间窗审查冻结风险结果：5个事件区域窗口均为中/高风险，6个相对低强度对照窗口均为低风险；另外7个事件前后上下文不计分。18份独立Risk JSON全部通过Schema、区域和`rule_status=frozen`验收。

## 必须保留的限制

1. 独立样本只有2个事件案例和2个相对低强度对照案例，不能据此声称对沙特全年或所有暴雨均达到完美技能。
2. 对照表示相对低强度，不等于已有可靠证据证明“无灾害影响”；上述分类首先是天气层阈值验证。
3. 区域最大值存在明显低估，all-leads Bias为-11.120 mm；当前较好的`spatial_p95`结果不能掩盖极值不足。
4. lead048的`spatial_p95`误差最大，需要在后续版本分析，但不得修改已经锁定的暴雨v2来改善本次结果。
5. 高温规则、GHCN正式时间口径和影响层评估仍未完成。Neo4j本地实机联调已于后续完成，但不改变本次独立暴雨指标。
