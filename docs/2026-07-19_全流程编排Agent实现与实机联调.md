# 全流程编排 Agent 实现与实机联调

日期：2026-07-19。

## 结论

仓库已实现“第二种”完整流程编排 Agent。它不再只是读取现成联合预测锁并撰写报告，而是从一个案例入口开始，受控组织以下完整研究链：

```text
案例与起报时间
  → GraphCast 缓存检查/缺失时获取
  → 24/48/72h MAZU-like NetCDF
  → NetCDF 契约与连续窗口校验
  → ADM1 指标摘要
  → 冻结基础规则 + 锁定知识图谱纠错规则
  → 无真值联合预测锁
  → Neo4j 在线写入与查询
  → Luna/Terra 综合报告
  → 运行清单与 SHA-256 溯源
```

这是一套研究原型编排能力，不代表实时业务预警已经获准。暴雨联合方案是 `research_candidate`；高温方案仍为 `research_only_blocked`，不能发布正式预警。

## 受控设计

编排 Agent 只能调用两个工具：查看状态、执行下一个合法阶段。状态机固定为八步，Agent 不能跳步、运行任意 shell、修改阈值或改写风险。每一步成功后原子更新 `workflow_state.json`；电脑中断或网络失败后，以相同 `run_id` 和完全相同的请求重跑即可从首个未完成阶段继续。相同 `run_id` 不能换案例、灾种或区域。

预测阶段严格保持 `truth_accessed=false`。运行时联合推断只读取：GraphCast/MAZU-like 预测特征、MAZU 2025 参考统计、development 拟合参数、联合选择锁。它不读取当前案例的 IMERG、SSOD、GHCN、灾害记录、命中、漏报或误报答案。真值只允许在预测锁完成后的独立 Verification 流程使用。

Neo4j 使用 `JointPredictionCase`、`JointForecastWindow`、`JointPredictionRegion`、`JointRule` 专用命名空间，并把 `run_id` 放入运行划分，避免不同运行互相覆盖。Luna/Terra 只能解释 Neo4j 返回的三窗口时间线，基础风险、图谱触发和最终风险均为不可修改字段。

## 实机结果

两条真实链均使用本地已存在的 GraphCast 缓存，实际经过 NetCDF 校验、ADM1 汇总、联合规则、Neo4j Bolt 在线写入/查询和中转 API 模型调用。

| 运行 | 编排模型 | 报告模型 | 重点窗口 | 基础风险 | 图谱触发 | 最终风险 | 状态 |
| --- | --- | --- | ---: | --- | --- | --- | --- |
| `20260719_rain_full_agent` | Luna | Luna | SA-09 / +48h | low | true | medium | complete |
| `20260719_heat_full_agent` | Terra | Terra | SA-04 / +48h | high | false | high | complete；正式预警阻断 |

两次运行的 Agent 工具轨迹均为：首次检查 → 依序执行八个阶段 → 最终检查。两份报告均为 `joint_forecast_live`、`live_neo4j`、`truth_accessed=false`，运行清单均为 `passed`。

## 使用方法

Neo4j 必须已经启动，本地忽略文件 `.env.agent.local` 与 `.env.neo4j.local` 必须存在。不要把密钥、密码或这两个文件提交到 Git。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_full_orchestrator_agent.ps1 `
  -RunId "20260719_new_case" `
  -CaseId "20200729_00" `
  -InitialTime "2020-07-29T00:00:00Z" `
  -Hazard "heatwave" `
  -RegionId "SA-04" `
  -FocusLeadTimeHours 48
```

若三份 MAZU-like 文件已经存在且通过校验，流程会直接复用；否则会通过现有可恢复 GraphCast 缓存模块补齐。若运行失败，修复 Neo4j、网络或配置问题后原样重跑同一命令即可继续。

## 边界与后续

- 当前入口支持仓库已验证的 2018/2020 历史 GraphCast 回放周期，不是实时天气数据接入。
- Agent 是流程控制者和报告解释者，不是数值天气模型，也无权修改冻结科学判断。
- 暴雨图谱纠错的独立新增收益仍待全新案例验证。
- 高温联合方案未通过全部 development 门槛，编排跑通不能解除其正式预警阻断。
- 上线生产仍需服务账户、密钥托管、任务队列、监控、备份和新的前瞻验证，这些不在当前结项原型声明内。
