2. `development` 与 `independent_test` 的划分是否冻结，独立测试案例不得参与阈值调整；
3. 天气层和影响层是否按上表分开评价；
4. 批处理前所需 GraphCast 历史输入是否可取得。

上述决定已经写入候选 catalog 并通过契约预检查。下一步是启动 GraphCast → MAZU-like 批处理；独立测试案例的结果不得用于调整阈值。
