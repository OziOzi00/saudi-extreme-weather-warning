# 评估协议

## 两层评估

1. **天气层**：预报的降水、温度、风及空间位置是否接近真实观测。
2. **风险/影响层**：区域风险结果是否与可靠灾害影响记录一致。

两层不可互相替代：天气预报正确不必然代表发生灾害，缺少灾情资料也不能证明未发生影响。

## 指标与数据

- 强降水优先使用 IMERG：24h 降水误差、命中/漏报/空报、CSI、空间 IoU、雨带中心偏差。
- 高温正式development评估使用SSODv2同步UTC站点日摘要：TMAX/TMIN的MAE、RMSE、高温日命中、热浪开始日与持续时间误差；GHCN因缺少`OBS-TIME`只作极值旁证。
- 灾害真值表至少区分 `yes`（有可靠影响证据）、`no`（有可靠证据表明无明显影响）、`unknown`（资料不足）。

天气层的标准配对契约、IMERG/GHCN/SSOD单位和时间处理、区域/站点匹配及运行命令见[天气观测接入与验证](天气观测接入与验证.md)。11个development案例的153条配对已闭合，并生成12行IMERG指标、24行SSOD指标和18行高温时序。它们只用于开发检查，不是independent_test结论。

当前代码可计算：

- 连续量：样本数、MAE、RMSE、Bias；
- 二分类：命中、漏报、空报、正确否定、POD、FAR、CSI；
- 高温序列：预报/观测开始 lead、开始误差、最长持续日数及持续误差。

只有`qc_status=accepted`的标准配对进入正式指标。IMERG必须与预测采用同一格点区域聚合；SSOD/GHCN都必须先把预测采样到相同站点，再采用相同的站点聚合。

GHCN的本地日界线未确认，不进入本轮正式配对。SSOD正式配对至少需要2站，并保留“天气学时次报告可能未捕获真实日极值”的限制。冻结配置为`configs/weather_verification_qc_v1.yaml`；IMERG阈值为空时分类字段必须为空。

暴雨v2冻结后，独立暴雨评估由`independent_heavy_rain_evaluation_lock.json`锁定规则、观测清单和4个案例。独立结果为P95命中6、漏报0、空报0、正确否定12；这组小样本结果不得用于回调规则，也不得外推为高温或影响层效果。

## 归因标签

事后复盘可使用：`weather_model_error`、`risk_rule_error`、`spatial_mapping_error`、`missing_observation`、`disaster_record_unknown`、`agent_reporting_error`。当前已有 development 与独立暴雨天气层指标，但尚未形成覆盖所有失败样本的系统化归因标签集；高温和影响层也不得借用暴雨结论。
