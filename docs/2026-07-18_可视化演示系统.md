# 可视化演示系统

## 定位

该页面是当前研究原型的本地研判与答辩展示入口，不是生产预警系统，也不构成沙特官方气象预警。它不重新计算 GraphCast、MAZU-like 或风险规则，只读取仓库中已经版本化的边界、Risk JSON 和评估清单。

## 启动

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_dashboard.ps1
```

随后打开 `http://127.0.0.1:8765`。如果端口被占用，可指定其他端口：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_dashboard.ps1 -Port 8877
```

脚本先执行 `saudi_warning.dashboard.build_data`，再使用 Python 标准库提供静态页面，因此队友无需安装 Node.js、前端框架或地图服务，也无需启动 Neo4j。

## 页面内容

- 沙特 13 个 ADM1 区域边界，来源仍为仓库中的 2017 geoBoundaries 参考层；
- 15 份 development 和 18 份 independent_test 冻结暴雨 Risk JSON；
- `20200725_00 / SA-14` 独立测试命中案例，可切换 24/48/72 小时时效；
- `20200501_00 / SA-09` 已知影响漏报，展示天气低估和规则空间尺度归因；
- 暴雨一次性独立评估、高温 development CV、影响层描述性覆盖和 Neo4j 本地联调状态。

页面的数据包是 `dashboard/data/dashboard_data.js`。该文件由构建器生成并提交，方便直接演示；修改源清单后必须重新运行脚本生成，不能手工改写统计值。

## 答辩材料导出

选择场景、案例和预报时效后，可使用页面右上角的两个按钮：

- `导出答辩图 PNG`：生成固定为 1600×900 的地图与证据卡片，适合直接放入幻灯片；
- `导出案例摘要`：生成 Markdown 文件，记录案例、区域、时效、风险、阈值、证据、漏报归因和使用边界。

两种导出都只读取页面当前选中的 Risk JSON，不重新计算风险，也不修改任何仓库文件。建议正式答辩材料同时保留一个独立测试命中案例和一个已知漏报案例，避免只展示成功结果。

## 严格边界

1. 暴雨 v2 是已冻结规则；页面不得用独立结果回调阈值。
2. 高温当前为 `blocked`，仅有 development 证据，独立高温尚未打开；页面没有高温区域风险图。
3. 影响层只有 6 个已审查正样本单元，覆盖 5 个；没有已审查负样本，不能报告影响准确率、精确率、特异度或空报率。
4. Neo4j 的 87 节点、152 关系和 6 约束只代表本地 development 联调通过，不代表生产部署。
5. 地图用于展示区域级聚合结果，不能解释为街道级或站点级预警。

## 验收

自动测试核对区域数、正式风险结果数、暴雨独立混淆结果、高温封存状态、影响层负样本缺口、成功/漏报案例和导出入口。运行：

```powershell
$env:PYTHONPATH = "$PWD\src"
python -m pytest -q
```
