# 成员 C：案例与灾害影响真值

本目录保存可提交 Git 的小型证据索引和结构化真值，不保存网页全文、截图或受版权保护的原始材料。

- `source_catalog.csv`：来源、访问日期和可靠性说明。
- `disaster_impact_truth.csv`：一行一个“事件—区域—影响类别—来源”证据记录。
- `../../configs/case_catalog_candidates.csv`：候选事件、候选对照和现有演示日期。

## 状态解释

- `yes`：来源明确报告了灾害影响。
- `no`：必须存在可靠的“无明显影响”证据；当前没有任何记录使用该值。
- `unknown`：资料不足。未找到新闻绝不能写成 `no`。
- `pending`：已结构化，但仍需成员 C 或全队复核；不能作为最终影响层评估结论。

候选对照日只完成了季节和区域匹配，仍需成员 B 使用 IMERG/GHCN 筛除异常天气，并由成员 C 检查影响资料。全队确认后，才把批准的行复制为本地 `data/external/case_catalog.csv` 交给 A 批处理。
